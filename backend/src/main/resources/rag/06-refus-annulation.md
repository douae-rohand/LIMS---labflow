# Refus et annulation

## Pourquoi une demande peut être refusée
Le laboratoire peut refuser une demande, par exemple si une analyse n'est pas réalisable, si les informations sont incomplètes ou si le laboratoire ne peut pas la prendre en charge. Le motif du refus est toujours indiqué dans le détail de la demande.

## Que faire après un refus
Lisez le motif indiqué. Selon le cas, vous pouvez envoyer une nouvelle demande corrigée ou contacter le laboratoire pour plus d'informations.

## Analyse non réalisable
Si une analyse ne peut pas être réalisée sur l'échantillon reçu, le technicien le signale avec un motif et le laboratoire vous informe de la suite.

## Demande sur place non finalisée
Pour une demande enregistrée à l'accueil, si l'échantillon ou le paiement n'est pas reçu dans les 48 heures, la demande est refusée automatiquement et sa facture est annulée par un avoir : plus rien n'est dû.
