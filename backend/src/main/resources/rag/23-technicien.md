# Guide du Technicien

## Le menu du Technicien
Le menu comprend : Tableau de bord, Mes essais, Planning, Import CSV.

## Tableau de bord
Le tableau de bord résume les essais à faire, la charge de la semaine et les prochains essais prévus.

## Réaliser un essai et saisir le résultat
Dans « Mes essais », ouvrez un essai affecté. Le détail montre l'échantillon, l'analyse et les étapes. Saisissez le résultat dans le formulaire prévu, puis enregistrez-le. Le résultat part ensuite en validation.

## Essai non réalisable
Si l'analyse ne peut pas être réalisée sur l'échantillon reçu, déclarez l'essai « non réalisable » en indiquant un motif. Le responsable en est informé.

## Résultat retourné
Quand le responsable retourne un résultat pour correction, l'essai revient dans vos essais avec son commentaire. Corrigez puis renvoyez-le. L'historique des validations reste visible dans le détail de l'essai.

## Planning
« Planning » affiche vos essais dans le temps (jour, semaine) pour organiser votre travail.

## Import CSV
« Import CSV » permet de saisir plusieurs résultats à la fois à partir d'un fichier CSV : déposez le fichier, vérifiez l'aperçu puis confirmez l'import.

## Domaines de compétence
Un technicien ne reçoit que des analyses de ses domaines de compétence (par exemple Biochimie ou Hématologie). Ces domaines sont attribués par l'administrateur du laboratoire.
